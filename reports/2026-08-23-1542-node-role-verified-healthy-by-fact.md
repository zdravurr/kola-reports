## 3. `tokens.node.scopes` — `[]`, И ПРАВИЛО ПРЕФИКСА ВЫПОЛНЕНО

```
Pixel 10a (100.85.178.10)  node.scopes = []   operator.scopes = 5
Galaxy Tab A11+ 5G         node.scopes = []   operator.scopes = 4
```

По `operator-scope-compat-BVrjvlGm.js:23`:

```js
if (requested.length === 0) return true;      // ← пустой список проходит на первой же строке
```

Пустой список **не доходит** до проверки префикса — он разрешён раньше. Именно поэтому `[]` работает,
а `['operator.admin']` не мог: для роли `node` требовался префикс `node.`, которого у operator-scope
нет и быть не может.

Тонкость, которую стоит знать: при `node.scopes = []` узел проходит, только если сам запрашивает
**ноль** scopes (иначе `allowed.length === 0 → false`). Android-узел именно так и делает — в журнале
`scopes=0`. Это ровно то состояние, что у Galaxy Tab и что было до 13:22.

**operator-токен Pixel сохранил `operator.admin` — я его намеренно не трогал.** Для роли `operator`
префикс `operator.` законен, эта половина работала всё время; чинить её было нечего.
