## 1. ПОЧЕМУ «ОТВАЛИЛОСЬ» — ОТВЕТ: НЕ ОТВАЛИЛОСЬ

| проверка | факт |
|---|---|
| Канон `item_records.bike_giant_rainier` | `status = sold` |
| `gone_note` в каноне | «ПРОДАН 23.08.2026. Приказ Босса 24.08: record it as a permanent fact, status=sold, not a pause» |
| `live_listings.json` → CL | `status = deleted`, `delisted_utc = 2026-08-24T21:10Z` |
| `delist_note` | «снят 24.08, статус подтверждён ПЕРЕЧИТЫВАНИЕМ площадки» |
| Публичная страница СЕЙЧАС (живая проба 30.08) | **HTTP 410 Gone** |

Живая проба, только что:

```
curl -sL .../7947463363.html
→ 301 → https://www.craigslist.org/view/d/trabuco-canyon-giant-rainier-26in/djZc7DKscApHKiasyJthU6
→ final HTTP 410
```

**410 — это НЕ поломка. Это наш собственный пруф снятия.** У частного объявления на Craigslist
нет статуса «sold»: только Edit / Delete / Renew. Поэтому «снять» = удалить, а доказательство
снятия — именно 410 на публичной странице.

Сами кроны бампа сняты 26.08 меткой `#STOPPED26AUG_EVENTDRIVEN`, и над ними в crontab уже висит
