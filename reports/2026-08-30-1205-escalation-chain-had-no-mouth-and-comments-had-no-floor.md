## 1. КЛАСС ДЕФЕКТА: ПУСТОЕ УМОЛЧАНИЕ, НАЗВАННОЕ РАЗДЕЛЕНИЕМ ОТВЕТСТВЕННОСТИ

В `attempt_ledger.guard` стояло дословно:

```python
# `on_block(why, summary)` — как именно докладывать, решает лестница (у каждой свой
# канал). Модуль НЕ выбирает канал за неё: единый судья ≠ единый рупор.
```

Звучит как архитектура. Работает как тишина: `on_block=None` по умолчанию, и правило
«а теперь доложи» жило копией в каждой лестнице — где его **забыли во всех**.

🔴 Это ровно тот дефект, о котором предупреждает **шапка этого же модуля**:
«правило, скопированное в каждого вызывающего, — это правило, которое забудут в следующем».
Модуль написали, чтобы отменить такой класс, и тут же воспроизвели его на один слой выше.

**Починка — не «звонить чаще», а дать выходу АДРЕСАТА ПО УМОЛЧАНИЮ.** Технический тупик
теперь едет в `tech_queue.file_from_watchdog`, который сам решает `classify_wall`
(техника или операционка), сам дедуплицирует и сам поднимает Колю. Босс видит только итог.
Лестница по-прежнему может передать свой `on_block` — но **молчание больше не является
значением по умолчанию**, а отказ от эскалации обязан быть ЯВНЫМ (`on_block=False`).

⛔ **Потолок не тронут.** Добавлен ТОЛЬКО рот. «Пробовать, пока не получится» — это и есть
сожжённые впустую токены; `MAX_SAME_BLOCKER=3` остаётся ровно там, где стоял.

Новая строка для лестницы — одна:

```python
cont, why, task = attempt_ledger.wall(ladder, blocker="…", path="…", component="…")
if not cont:
    break        # остановились, задача заведена, улики уехали
```

## 4. КОНТРАКТ ПОЙМАЛ МЕНЯ САМОГО — И ЭТО ЛУЧШАЯ УЛИКА ЗА ДЕНЬ

Первый прогон набора дал **160/161**. Упал `test_escalation_declares_whether_goal_resumes`

починки». Мои новые места молчали.

Соблазн был передать `resume` с запуском захода прогрева. **Это было бы ошибкой:** заход
поднялся бы **вне окна Огня** — ровно дефект задачи `486e90f996c1` (28.08) — и подрался бы
за экран с money-path.

Правильный ответ: **у повторяющейся цели механизм возобновления — её собственное
РАСПИСАНИЕ**, и оно сильнее `resume`. Рост встаёт сам на слоте 10/16/22 UTC, максимум через
8 часов. Это записано долгом с причиной.

🔴 И вскрылся шов, который я едва не оставил слепым пятном: тот контракт судит
**синтаксически** — по наличию `resume=` в вызове очереди. Пропустив вызовы через общий
рот, я сделал бы все лестницы для него невидимыми: он видел бы один `attempt_ledger` и
всегда «зелено». Поэтому решение спрашивается **в самом рту**: `_escalate` требует либо
`resume`, либо `resume_debt` с причиной, и ответ едет **в улики** — Коля видит, встанет ли
цель, ДО того как закроет задачу.
