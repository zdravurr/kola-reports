# «Принято» больше не состояние работы. Хоп починен (22.08.2026, 16:50 UTC)

**Коротко.** Задача Босса теперь **исполняется кроном**, а не закрывается словом. Закрыть её
как отправленную **без пруфа больше нельзя** — отказ выбрасывает исключение. 21 застрявшая
задача разобрана **поштучно**. Приказ «байк продан» закрыт как **устаревший** — велосипед в
продаже, **ни одно объявление не снималось**.

---

## 1. ЧТО БЫЛО И ЧТО СТАЛО

**Было** (`projects/dirigent/dirigent.py:266-269`):
```python
for t in dc.open_worker_tasks("senya", ctrl):
    alarm("✍️ СЕНЯ (задача Босса): … Возьму в штатном проходе лида.")
    dc.close_worker_task(t["id"], "ack")      # ← закрывал, НЕ отправив
```

**Стало** — `scripts/worker_task_runner.py`, крон `*/2`, сессия не нужна:
- отправляет через **тот же гейтованный путь**, которым сегодня ушли Кларита и Марио
  (`send_to_sender_native`: навигация с проверкой личности треда, `review_gate`, анти-дубль,
  PII-гард, пост-проверка чтением экрана). **Своего пути отправки здесь нет и быть не должно;**
- закрывает **только по пруфу `CARRIED`**; не ушло — `blocked` с причиной **и докладом Боссу**;
- одна задача за прогон, `flock` против гонки, потолок 3 попытки, рубеж боевого состояния
  перед касанием экрана.

`dirigent.py` senya-задачи больше **не закрывает вовсе** — два потребителя одной очереди
дрались бы за экран и могли отправить покупателю дважды.

## 2. СЛОВАРЬ СОСТОЯНИЙ: «ПРИНЯТО» УДАЛЕНО

```
sent     — ОТПРАВЛЕНО, требует пруф. Без пруфа закрытие ОТКЛОНЯЕТСЯ исключением.
blocked  — НЕ отправлено, требует причину.
```
`ack`, `queued`, `done` теперь отвергаются близко к вызову:

```
close_worker_task(tid, 'ack')  → ValueError: у задачи два исхода — 'sent' с пруфом
                                 или 'blocked' с причиной. «Принято» состоянием работы не является.
close_worker_task(tid,'sent')  → ValueError: 'sent' БЕЗ ПРУФА запрещён
```

Отказ намеренно **громкий**: вернуть «принято» случайной строкой кода не должно быть возможно.

## 3. ТРЕТИЙ ДЕФЕКТ ТОГО ЖЕ ХОПА: У ЗАДАЧИ НЕ БЫЛО АДРЕСАТА

Задача `reply` хранила **только текст**:
```
wt_1786895864 :: "Address to pick up the bike: 32 Milkwood…"   ← имени НЕТ
```
Босс говорит «ответь Кларите», а в очередь ложился текст без Клариты. **Отправить такое
физически некуда** — и это, судя по всему, и есть причина, по которой исполнение когда-то
подменили словом «принято». Теперь адресат едет вместе с задачей, а команда без адресата
**не заводит пустышку**, а переспрашивает.

## 4. ЧТО НАШЛОСЬ ПО ДОРОГЕ — СВОИМИ ЖЕ ПРОВЕРКАМИ

Отсюда рубеж боевого состояния **в самом исполнителе**: полагаться на дисциплину теста нельзя.

🔴 **`_extract_thread_target` вместо «не знаю» вернул ВЕСЬ ТЕКСТ в роли имени** —
`target: "Здравствуйте Сожалению Доставки Нет Только Самовывоз…"` — и обошёл мою же проверку.
Для ответа адресат теперь обязан совпасть с **живым тредом**.

🔴 **Строгая сверка отказывала ВСЕГДА:** на «ответь **Кларите**» она не видела тред
«Clarita N» — Босс говорит по-русски и склоняет имена, треды подписаны латиницей. Добавлена
сверка по «скелету» (кириллица→латиница, c/k, падежные окончания):
```
Кларите → Clarita N   Кларитой → Clarita N   Clarita → Clarita N   Несуществующему → None
```

🔴 **Гонка кронов:** `*/2` против отправки в 3–5 минут — второй тик вошёл поверх первого
(16:42 → 16:44) и начал ту же задачу заново. Поставлен `flock`. Проверено живьём:
`исполнитель уже идёт — этот тик пропускаю`.

⚠️ **Я сломал настоящего вызывающего** — `dirigent_worker_guarantee.mark_done(tid,"done")`.
Починено по существу: теперь требует улику, а старый контракт, кодировавший прежний закон,
обновлён и **усилен** — отдельной строкой проверяется, что закрытие без пруфа отклоняется.

## 6. ЖИВАЯ ПРОВЕРКА

**Команда БЕЗ адресата** — пустышка не заводится:
```
Босс: «Ответь покупателю, что доставки нет»
Дирижёр: «Понял, отправлю. Только скажи, кому именно — назови покупателя по имени треда…
          по тексту угадывать адресата не буду: послать не тому хуже, чем переспросить»
задач 22 → 22 : ПУСТЫШКА НЕ ЗАВЕДЕНА ✅
```

**Команда С адресатом** — задача заводится с адресатом и уходит крону:
```
Босс: «Ответь Кларите, что велосипед всё ещё в продаже за 100 долларов»
Дирижёр: «Задачу принял в работу — исполнитель откроет тред и отправит с телефона в
          ближайшие пару минут, закрою только по пруфу отправки. Если гейт или экран
          не пустят — вернусь с причиной.»
ЗАДАЧА: {"id":"wt_1787416817_aa27f3","target":"Clarita N","status":"open"}

16:42:05 ▶ экран взят, отправляю 'Clarita N' (попытка 1)   ← КРОН, без всякой сессии
16:48:02 исполнитель уже идёт — этот тик пропускаю          ← замок держит
```

**Ключевое отличие от прежнего мира:** задача **не закрылась**. Раньше она в этот момент уже
была бы `ack`. Теперь она остаётся `open`, пока не появится пруф, а после трёх попыток станет
`blocked` с причиной — и причина уедет Боссу.

⚠️ **Честно про этот прогон:** Кларите в 16:21 уже ответил штатный воркер Сени
(`CARRIED: «You can reach Radomir directly at 949-990-9583…»`), поэтому попытка крона упирается
в анти-дубль — то есть проверка идёт по пути «честный отказ», а не «успешная отправка».
Путь `sent` доказан в контракте (22 проверки) и **дважды живьём сегодня** тем же примитивом:
`CARRIED Clarita N` в 15:59 и `CARRIED Mario` в 16:05.

**Контрактов 61/61.** Новый контракт — 22 проверки: запрет `ack`, `sent` без пруфа, `blocked`
с причиной, адресат в задаче, отказ без адресата, закрытие по пруфу, гард → `blocked`.

## ЧЕСТНО О НЕЗАКРЫТОМ

- **Сверка имён покрывает не все:** «Мишель»/«Хизер» по скелету не совпадают с
  `Michelle`/`Heather` (ш↔ch, х↔th). Система в этом случае **переспрашивает**, а не гадает —
  направление верное, но Боссу придётся называть их латиницей.
- **Живой `sent` через крон в этом прогоне не доказан** — помешал анти-дубль от собственного
  штатного ответа. Первая же команда в незанятый тред это закроет.
- `item` у задачи пока не заполняется командой — у тёзок навигация откажет (fail-closed).
