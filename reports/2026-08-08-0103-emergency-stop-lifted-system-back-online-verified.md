### 4.1 `main_liveness` — БЫЛ ПОЧИНЕН 02.08, и я доказал ОБЕ ветки в один день

Правка 02.08: `ping_main()` возвращает ТРИ вещи, а `if ping_main():` читал `None`

| реальных рестартов гейтвея | |

| 02.08 | 90, затем правка в 14:52 |

Сегодня видно ОБА состояния на одном сторожe:

```

00:40 / 00:50 / 01:00  (стоп снят)   [ping] ok: жив  →  [ok] main жив — тихо
```

`last_ok` впервые с 28.07 сдвинулся на 01:00:02. Класс закрыт: «не спрашивали» ≠ «мёртв».

### 4.2 🔴 НОВАЯ НАХОДКА: `wake()` рапортует УСПЕХ агенту, которого НЕ СУЩЕСТВУЕТ

Я позвал `wake('senya', …)`. Получил `True` и строку в аудите:

```
[WAKE] session_verify → senya (ок: занято 4/6 …)
```

А на деле: `openclaw agent --agent senya` → `Error: Unknown agent id "senya"`.
Настоящие агенты — `worker1/worker2/worker3`. Спавн умер мгновенно, stderr ушёл в DEVNULL,
`wake()` вернул True по факту успешного `Popen`, **аудит записал пробуждение, которого не было**,
и слот брони протёк.

**Почему это опаснее, чем выглядит.** В `route_to_main` `delivered=True` означает «лид
доставлен» → метка дедупа ставится, а в `watcher_blocked_leads.jsonl` лид НЕ едет.
Промах в имени агента = **лид исчезает молча и навсегда**.

**Боевой код сегодня ЧИСТ** — все вызовы идут каноническими `worker1/2/3`
(`LANES = {"worker3": "sales", "worker2": "procurement", "worker1": "warmup"}`). Дефект
ЛАТЕНТНЫЙ. Но ловушка заряжена: `agent_capacity._agent_lane()` САМ принимает «senya»/
«borya»/«ogon» как валидные имена для гейта полосы — то есть один и тот же модуль
считает эти имена годными для проверки и негодными для запуска. Я на это и наступил.

а полоса `warmup` стояла на ОТДЕЛЬНОЙ паузе пульта Дирижёра. Пруф, что это разные замки —

```
2026-08-08T00:30:02Z [run_guarded] SKIP fbwarmup — warmup lane paused (Дирижёр)
```

Честно: этот слот отработал в 00:30, ДО снятия стопа в 00:35, а `run_guarded` проверяет
полосу первой и до горла экрана не доходит. Так что строка доказывает «крон жив и полоса
кусает», но НЕ доказывает, что стоп ушёл с пути Огня.

**По твоему решению полоса поднята:**
`ogon_gate.allowed()` → `(True, 'окно открыто, полоса «прогрев» live')`.
Дополнительную активность НЕ форсирую. Ближайший натуральный слот — **10:00 UTC** (xwarmup,
оба аккаунта X), затем 11:30 fbwarmup. Пруф принесу из `system_guard.log` по факту.
