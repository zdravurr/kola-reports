# 7c2314733c3e — «Огонь не производит (posts) @zdravurr_ca»: молчание было ЗАКОННЫМ, слеп был судья

## Что оказалось на деле
Постов сегодня действительно ноль. Но производство не сломано: **с 05.09 22:41 UTC жив
аварийный стоп Босса** (`.kola_state/pause/EMERGENCY_STOP`, `who: boss`, `why: голосовая
команда «стоп всё»`). Прогрев под запретом владельца законно не запускался — последняя
запись журнала @zdravurr_ca 05.09 13:39, отложенный слот подхватился в 22:30, а в 22:41
Босс всё остановил.

Тревога, поднявшая эту задачу (4-й подъём), — **про прибор, а не про продукцию**.

## Корень
`lib/ogon_quota.py`, `lawful_zero_reason()` спрашивал стоп **мёртвой формой вызова**:

```python
import emergency_stop as _es
if not _es.is_running():        # такой функции в модуле НЕТ (живая — is_stopped())
    return "аварийный стоп Босса"
except Exception:
    pass                        # AttributeError уходил в тишину
```

`AttributeError` глотался общим `except`, и отказ прибора читался судьёй как «законной
причины нет» → ежечасный `🔴 ДЕФИЦИТ`, техзадача, а по комментам ещё и **разбуженный Босс**
(15:17: «comments — доложено БОССУ»). Проверил живьём: `is_stopped() → True`,
`hasattr(es,'is_running') → False`.

Класс известный, третий случай за двое суток: **прибор мерит несуществующей формой вызова,
а его отказ проглочен** (05.09 — проба генерации, 06.09 — свип инбокса). Пустой ответ
сломанного опроса ≠ улика.

## Что починил
1. **Живая форма вызова** — `_es.is_stopped()`. Стоп Босса снова виден судье квоты.
2. **Отказ опроса называет себя.** `lawful_zero_reason(with_blind=True)` возвращает вторым
   значением, какой именно опрос владельца правил не состоялся (с типом и текстом
   исключения). Все четыре `except`-а перестали быть немыми.
3. **Ослепший прибор не даёт красного.** Если законный ноль проверить не удалось, судья
   пишет `ПРОВЕРКА НЕ СОСТОЯЛАСЬ — законный ноль не опрошен (…); дефицит N не сужу` —
   и не заводит задачу, и не будит Босса. Молчать тоже нельзя: ослепление видно в журнале
   отдельной строкой `⚠️ ЗАКОННЫЙ НОЛЬ НЕ ПРОВЕРЕН`.
4. Глушилку не завезли: при живом приборе и снятом запрете дефицит объявляется как прежде.
