## 2. ЧТО ПОСТРОЕНО — ЗАМОК, А НЕ ЗАПЛАТКА

### `lib/buyer_alert_gate.py` — ОДИН привратник для ВСЕХ ртов

Ни одна тревога «покупатель ждёт» не звучит, не спросив **оба** источника:

- **(a) ледджер приказов Босса** — `boss_rulings.json` + хардкод `BOSS_NOT_OURS`, по паре
  (имя, листинг) и по имени целиком (консервативный судья: у имени есть хоть один тред,
  приказом не закрытый → судить по имени отказывается — тёзки не глушат друг друга);
- **(b) канон вещи** — `item_records`: **ПРОДАННАЯ вещь не рождает ждущего покупателя
  НИКОГДА**, ни при каком приказе и ни при каком возрасте треда.

**Направление отказа сохранено в сторону покупателя.** Гасим только по ОДНОЗНАЧНОМУ
записанному факту. Судья недоступен, вещь не опознана, приказа нет — **тревога звучит**.
Обе причины блокировки печатаются в лог: молчание сторожа само не становится фактом без улики.

### Привратник вшит во ВСЕ пути, а не в тот, который поймали

| Путь | Что было | Что стало |
|---|---|---|
| `fb_inbox_sweep` — крик | только «исход Дирижёра» | привратник стоит ПЕРВЫМ, раньше лестницы исходов |
| `fb_inbox_sweep` — роут к Сене | не спрашивал никого | тот же привратник, **до** предохранителя от лавины (порог мерит реальную нагрузку) |
| `fb_inbox_sweep` — флаг приоритета экрана | `_ruled_out or _item_dead` | + привратник: приказ `closed` тоже снимает флаг, прогрев не уступает экран несуществующему покупателю |
| `autoresponder` | НИЧЕГО — тот же отравленный ледджер кормил ВТОРОЙ рот, который и звонил, и ШЁЛ ОТВЕЧАТЬ | привратник |
| `answer_guarantee` | свой глушитель судит ПУСТОТУ счёта, не приказ и не вещь | + привратник, счёт снимается с уликой |
| `lead_guarantee` | знал только парковку | + привратник по имени из лид-обязательства |

### `item_records`: новый вид приказа `closed`

Heather **была нашим покупателем по НАШЕЙ вещи**. Записать её `not_ours` («ЧУЖОЕ, мы там
покупатель») значило бы положить в ледджер **ложный факт ради тишины сторожа** — ровно то,
что запрещено стоячим правилом 26.08 про постоянного фантома. Приказ «не отвечай» и
утверждение «вещь чужая» — разные вещи, и ледджер обязан их различать.

`closed` = «наш тред по нашей вещи, Босс закрыл: ни ответа, ни лида, ни тревоги».
`boss_not_ours` от него по-прежнему возвращает False — ледджер не врёт про принадлежность.
